# FlowCare icon family

Original lowercase typographic marks outlined from the bundled Plus Jakarta Sans font at weight 800 (SIL Open Font License, bundled separately with the website font). These are independent role icons for a fictional offline healthcare demo.

- Patient: fc, cream on cobalt.
- Doctor: dr, cream on navy.
- St. Mathew Hospital: sm, navy on cream.

Each adaptive foreground is centered within a 61×47 dp maximum area in its 108 dp canvas. Website SVGs have softly rounded 25 px corners and a restrained 3 px border. No external logo or hospital affiliation is implied.
