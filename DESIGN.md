# FlowCare — blue and cream native design

The user-supplied DESIGN.md is a visual reference, adapted by the user's explicit request: restrained neo-brutal styling, more blue and cream, rounded edges, large controls, minimal cognitive load for adults and older adults. It supersedes the previous muted palette.

## Palette

Cobalt #2454C6; deep navy ink #162E58; cream #FFF8E8; warm paper #FFFDF5; pale blue #E1EAFE. Use blue for the single main action, cream for the canvas, ink for text and 2 dp outlines. Preserve semantic error messages in a contrasting dark red. Dark appearance uses navy surfaces and light blue controls.

## Type and controls

Bundled Plus Jakarta Sans. Body 18 sp / 28 sp, supporting copy at least 16 sp, buttons 18 sp semibold, headings 26–30 sp. JetBrains Mono only for identifiers and tokens. Follow system font scaling; do not crop headings or tighten body tracking.

Buttons: at least 64 dp tall, 20 dp corners, explicit text labels, 2 dp outline and 16 dp separation. Only the main action gets a blue fill and a small 3×4 dp solid offset shadow. Cards: 24 dp corners, 2 dp outline, no shadow. No gradients, decorative icons, automatic carousels, flashing, cropped typography or marketing imagery.

## Cognitive load

One main action per screen. Home shows booking and existing visits before other care options. Theme controls live in Settings. Keep Home/Back and Settings predictable; wrap groups at large text sizes. Plain language and explicit offline, loading, empty, success and error states. Keep clinical information and sensitive temporary text distinct from durable operational data.

## Reference adaptation

Carry over the uploaded reference's confident cobalt, rounded controls, generous spacing and clear hierarchy. Cream replaces electric sky-blue flooding. Healthcare task completion takes priority over its marketing-scale typography and full-bleed photography. The user's explicit neo-brutal and accessibility requirements override the reference's outline-only button rule and the prior no-shadow default.
